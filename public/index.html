📁 Opsi 1: Sinkronisasi Otomatis ke Google Drive Komputer

Jika Anda memasang aplikasi Google Drive for Desktop, masukkan lokasi folder sinkronisasi Google Drive Anda (misal di drive G:\My Drive\Backup Toko):

📥 Opsi 2: Unduh File Cadangan Database (.db) Sekali Klik

Unduh salinan file database ke komputer Anda. File ini bisa langsung Anda drag-and-drop / upload ke drive.google.com melalui browser.

✉️ Opsi 3: Kirim Cadangan & Laporan ke Gmail

Kirim file cadangan dan rekap keuntungan langsung ke email Gmail Anda. Dari Gmail, ada tombol langsung "Simpan ke Drive".

🔄 Pulihkan Data Database dari Google Drive (Restore)

Gunakan fitur ini jika Anda baru saja menginstall ulang komputer, ganti komputer baru, atau ingin mengembalikan seluruh data toko dari file cadangan yang sebelumnya disimpan di Google Drive.
